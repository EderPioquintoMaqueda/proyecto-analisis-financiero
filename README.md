
# Financial Data Analysis Project

Proyecto de análisis de datos financieros utilizando Python.

## Objetivo / Objective

Analizar ingresos, gastos y balances financieros mediante herramientas de programación y ciencia de datos.

## Tecnologías / Technologies

- Python
- Git y GitHub
- NumPy
- pandas
- Matplotlib
- Seaborn
- SciPy
- scikit-learn
- SQL

## Funcionalidades actuales / Current features

- Registro de transacciones financieras.
- Cálculo de ingresos y gastos.
- Cálculo del balance financiero.
- Conteo de transacciones.
